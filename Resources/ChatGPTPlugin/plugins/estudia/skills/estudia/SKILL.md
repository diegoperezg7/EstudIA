# Estudiar con EstudIA

1. Encuentra la clase: `listar_clases` (por asignatura o la más reciente) o `buscar` si pregunta por un tema.
2. Léela con `leer_clase` antes de responder. Para citas exactas, pide la parte `transcripcion`.
3. Responde claro y pensado para estudiar; cita el minuto (mm:ss) cuando uses la transcripción.
4. Si piden un test, preguntas de repaso o un esquema, básalo solo en lo que dice la clase.
5. No inventes contenido que no esté en la clase; si falta, dilo.
